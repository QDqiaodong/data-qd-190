# 可撤回教学样本库 v1

`showdown-corpus` 把真实课堂里的分池案例整理成可离线分发的习题库。维护端把每手牌按 v1 单手规则完整结算后，只把**按座位编号表示的结算题**收录进私有库；分发端只读取约定路径上的一个完整 JSON 文件，不访问私有目录，也不调用维护命令。结算复用 `showdown-pots` 的 v1 规则，不重新解释下注街次，也不连接资金或游戏服务。所有金额都是整数筹码。

旧命令 `showdown-pots`、`showdown-ledger`、`showdown-audit`、`showdown-reconcile` 的契约、数据格式与错误行为不变。

隐私边界：公开包不含姓名标识、来源桌号、原始牌面（含最佳五张）、私有路径或授权表，但**不承诺匿名性**；已被他人复制的旧文件**不追收**。参与者撤回后，固定路径上的当前代不再提供已撤回的样本。

## 状态与命令

私有状态是一个本地 SQLite 文件，只要求单写者顺序操作，读者只读公开文件。三个命令都写 `--state PATH`，成功时在 stdout 返回一个 JSON 对象；非法输入、未知库、禁止的变更都在 stderr 说明并以状态 2 退出，不留下部分收录、授权变动或新代文件。存储错误不会报成功。

```sh
showdown-corpus --state corpus.db init --public dist/package.json
showdown-corpus --state corpus.db apply --source batch.json
showdown-corpus --state corpus.db recover
```

### init

```sh
showdown-corpus --state corpus.db init --public dist/package.json
```

建立空样本库，并把公网分发前的本地交接文件路径固定在状态上（以绝对路径保存）。成功时该文件是第 0 代空包 `{"generation":0,"lessons":{},"objects":{}}`，返回 `{"generation": 0, "public": "<绝对路径>"}`。

- 已有状态、已有公开文件都不会被占用；私有状态和公开文件不能指向同一路径。
- 初始化后的公开文件仅由本工具维护；初始化失败会清掉自己刚创建的一半文件，不留半成品。

### apply

```json
{"samples": [{"sample_id": "x1", "lesson_id": "L", "table_id": "T1",
              "hand": { ... v1 单手输入 ... }}],
 "permissions": [{"player_id": "A", "allowed": true}]}
```

- `samples`、`permissions` 两数组必填，分别至多 100、1000 项，不可同时为空；全库最多保存 2000 个样本。
- `sample_id`/`lesson_id`/`table_id` 沿用仓库 ID 字符规则（`[A-Za-z0-9_:-]{1,64}`）。`sample_id` 是教务预先分配、可以公开的编号，全库唯一；样本一旦收录不改写，也不能再用同一 ID 收录（即使内容完全相同）。
- 每个 `hand` 都须是可按当前 v1 完整结算的输入，即使该样本暂时不能公开；不合法则整批不生效。
- 权限项以玩家 ID（而非座位）识别人，`allowed` 为布尔；同批不能重复更新同一玩家。没有授权记录视为不同意。权限可以先于样本录入，也可以同批到达：判断用的是**整批生效后**的权限，先导入再授权与先授权再导入结果相同。
- 合法但暂时不可公开的样本仍保留在私有库里；之后权限或主题门槛变化时自动重新判断，不需要也不能重新导入。

每次合法批次成功安装后代号加 1，即使可见内容未变。返回：

```json
{"generation": 3, "recorded": 1, "samples": 6, "visible_lessons": 1, "visible_samples": 2}
```

（`recorded` 为本批新收录样本数，`samples` 为全库样本总数。）

### 授权与主题门槛

- 每个样本要求该手的**全部**参与者当前均同意：包括弃牌者、未获筹码者和投入为零的参与者。只要有一位不同意，该样本就不公开。
- 按主题独立判断门槛：只在逐手授权合格的样本中数不同的内部 `table_id`，达到 2 张才公开该主题内**所有**授权合格的样本；同桌多手计数仍是 1，不能用另一主题的桌数凑门槛。未达标则整个主题不出现。
- 授权按手判断、门槛按桌计数：同桌某手因参与者撤回而失格时，只要该桌还有另一手合格，桌数不变，其余合格手仍可见。

### recover

```sh
showdown-corpus --state corpus.db recover
```

用同一私有状态在新进程中恢复一致性，不重读任何原导入文件。返回 `{"generation": N, "action": "none" | "published"}`：`none` 表示固定路径已是最新代；`published` 表示补发了已提交但未可见的一代。无待恢复批次时重复恢复不变代。

## 公开包格式

固定路径上始终是一个完整 JSON 文件（对象键排序、无空白分隔符、UTF-8、无末尾换行）：

```json
{"generation": 5,
 "lessons": {"L": [{"sample_id": "x2", "digest": "…"}, {"sample_id": "x3", "digest": "…"}]},
 "objects": {"<digest>": { ... 结算题 ... }}}
```

- `lessons` 是主题 ID 到样本数组的映射，各项只有 `{sample_id, digest}`，数组按样本 ID 的 ASCII 顺序排列；未达标主题整个不出现。
- `objects` 是摘要到结算题的映射，只含可见样本引用的题；同一题有多少可见来源都只放一个对象，但每个样本引用都保留。隐藏样本不进入包，也不留占位、数量或撤回说明。

结算题只含以下字段（金额均为 v1 整数筹码）：

- `button_seat`；
- `players`：按座位号升序，每项仅 `{seat, folded, committed, net}`；
- `pots`：按 v1 池号排列，每项仅 `{pot, amount, eligible_seats, winner_seats_in_odd_chip_order, awards}`；资格顺序与 v1 一致，获奖者顺序保留 v1 的并列余筹顺序，`awards` 的键为十进制座位号字符串；
- `uncalled_returns`：保留 v1 退回条目及顺序（含 `from_exclusive`/`to_inclusive`），只把 `player_id` 换为 `seat`。

`digest` 是结算题 JSON 以对象键排序、无缩进或分隔符空白、UTF-8 无末尾换行编码后的 SHA-256 小写十六进制；散列不含任何来源身份。只换玩家 ID、重排输入玩家数组而结算语义不变，得到同一摘要。读者从本代文件就能核对摘要并取得每个可见样本的结算题，不需要上一代或私有目录。

## 代次、可见性与成功回执

- 每个批次作为整体安装：先校验整批（结构、重复身份、牌谱可结算），再把样本、授权和渲染好的新代包在同一个 SQLite 事务里提交，最后用一次原子重命名替换固定路径。读者打开固定路径时只能看到上一代或完整新一代，不会看到逐步删除引用、对象暂时缺失或混代。
- **成功回执**（退出码 0 及 stdout 的 JSON）表示：该批已收录，且新一代已在固定路径完整可见。
- **未获回执**（进程被杀、存储错误、超时）时，这一批的效果未知：可能尚未提交（整批放弃），也可能已提交但尚未可见。此时不要凭猜测重试；先运行 `recover`（幂等、不加代），再读固定路径上的 `generation` 核对。若重放同一批样本时报 `sample_id already recorded`，说明该批其实已经收录。
- 恢复边界：中断时若新代尚未可见，恢复放弃（未提交）或完成（已提交）该批，私有收录和授权与最终公开代一致，不会留下半批私有事实；若新代已可见，恢复保留该批的全部效果及代号，不重新加代。新旧两代可见内容相同也遵守同一边界。新文件一旦可见，任何后续恢复都不会让固定路径回落到更早的版本；撤回成功后也不会回落到撤回前版本。

## 验收示例

平局牌：按钮 0，公共牌 `Tc Jc Qc Kc Ac`，座位 0、1 底牌 `2d 3d`、`4d 5d`，座位 2 弃牌且无底牌，三人各投入 1。结算题只有一个 3 枚的池，获奖座位顺序 1、0（分获 2、1），座位 0、1、2 净额 0、+1、−1，无退回。只改参与者 ID 或输入顺序的样本都映射到同一个对象与摘要。

1. 主题 L 的 x1、x1b（桌 T1，弃牌者都是 A）全部授权仍不可见；加入 L 的 x2（T2）与主题 M 的 y1、y2（T3、T4，y1 弃牌者 E，参与者 ID 互不交叉且均授权）后，五个样本引用同一个对象。
2. 只撤回 A：x1、x1b 失格，L 只剩一桌不达标，只剩 M 的两个引用，共用对象保留。再只撤回 E：M 不达标，两个映射均为空。加入 L 的 x3（T5，全部授权）后重新发布 x2、x3 与同一对象，x1、x1b 不恢复。
3. 仓库 `fixtures/input.json` 作为达标主题中的一手：投影池金额 80、90、40，退回为座位 0 的 30（`from_exclusive` 70、`to_inclusive` 100），按座位净额 60、−50、60、−70；退回不是另一池，侧池资格不丢弃。

完整可执行版本见 `tests/test_corpus.py`。

## 边界

仅支持单写者顺序操作与本地文件读者；没有下注街次合法性审查、抽水或真实资金接入；不依赖网络服务。公开包是可离线核对的教学数据，不是实际赌场结算认证。
