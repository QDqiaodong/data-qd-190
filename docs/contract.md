# 摊牌与边池 v1

用于教学牌局记录的确定性结算，不连接资金、游戏服务器或下注服务。输入固定5张公共牌、2..9玩家及button_seat(0..8)。玩家id唯一、seat唯一0..8、committed为非负整数筹码≤10^9、folded为布尔；未弃牌者必须提供2张hole，弃牌者可空或2张。卡牌为23456789TJQKA + cdhs的2字符标记；全部已知牌（含弃牌已知牌）不许重复。至少一个未弃牌者、至少一枚投入筹码。这里不复核完整下注街次、盲注、下注合法性或实际资金归属。

每个未弃牌者在7张中枚举21个5张组合。牌型高至低：同花顺、四条、葫芦、同花、顺子、三条、两对、一对、散牌；同牌型按标准化点数向量字典序比较，A2345顺子高点为5，QKA23不算顺子。花色不破平。输出rank和best_five作为核验凭据；等牌力组合以已排序卡牌ASCII序列最小者作证明，牌力不依赖证明排序。

按正贡献水平升序分层，层额=(本层水平-前水平)×达到本层的贡献人数。只有1人的层作为uncalled_return退回此人（不受folded影响）；这表示未被匹配筹码，并不假定弃牌/下注的完整历史合法。其余层为独立池，资格只给达到本层且未弃牌者。若匹配层无任何有资格者，输入无法按此模型解释而整体失败，不把钱分给无投入资格的人。

每池给有资格者最高牌力，平局整数均分，余数每人1枚，沿固定9席环从button之后按seat递增（越8回0）发给赢家，空席跳过。保留贡献者、资格者、赢家顺序和逐池金额。无抽水、保险、奖金、不同币种或多次发牌。逐人net=池奖+退回-投入；全局奖额+退回=全部投入、净额和=0。样例240投入，210分池、30退回，净额[60,-50,60,-70]。

非法输入退出2且不生成结果；有效记录先计算全部牌力和层级后原子新建JSON，不覆盖已有目标（含链接）。输出是教学数据模型结果，不是实际赌场结算认证。
